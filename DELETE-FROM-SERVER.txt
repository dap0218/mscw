All pages are now .html instead of .htm.
After uploading the new .html pages, delete every old *.htm page from the server
(e.g. home.htm, about_MSCW.htm ...). web.config now sends any old .htm address
to the matching .html page with a permanent (301) redirect, so bookmarks and
search-engine links keep working.

If the server's default document is set to home.htm, change it to home.html
(IIS Manager > the site > Default Document).
